The config file (`~/.config/opencode/opencode.json`) has been updated to `moonshotai/kimi-k3`, but you must start the next session with a fresh `opencode` command (not `occ` / `--continue`) for k3 to load.

## Gotchas learned the hard way

- **Do not save SaludConTech work in `/home/djtl/Projects/ligazon` or `/home/djtl/Projects/saludcontech-site`.** The canonical folder is `/home/djtl/Projects/saludcontech-website`.
- **The Cloudflare Pages project is named `saludcontech-relaunch`, not `saludcontech-website`.** Wrangler/API calls must use that name.
- **The Pages API token in the old `HANDOFF.md` is exposed and lacks DNS scope.** Rotate it and create a new token with `Zone:Read`, `DNS:Edit`, and `Cloudflare Pages:Edit` if you want full API automation.
- **COMPA PostHog config lives only in the PostHog web UI; there is no GitHub repo copy.** It must be captured manually from the browser.
- **`occ` / `opencode --continue` resurrects the old session model.** Always start a fresh session after model config changes.
- **Names of real people never go in git.** The Slack digest is already paraphrased; keep it that way.
